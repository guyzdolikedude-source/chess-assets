# chess-assets

A growing collection of chess-related visual assets from [Chess.com](https://www.chess.com/), Sashité, Chessperiment, and other chess projects. The repository is a simple place to find piece sets and other resources for chess-related work.

> [!WARNING]
> Chess.com-originated assets are kept separately in [`chess-com-assets/`](./chess-com-assets/). They may be protected by copyright, trademark, and Chess.com terms of use. This repository does **not** grant permission to reuse them. Review the collection warning and obtain any required authorization before copying, modifying, distributing, or using those assets.

## Assets

### [misc assets](./misc%20assets/)

The first collections are standard western chess-piece sets from two projects:

- [`sashite/`](./misc%20assets/sashite/) — public-domain SVG pieces from [Sashité's Chess Assets](https://sashite.dev/assets/chess/), organized into `white/` and `black/` folders.
- [`chessperiment/`](./misc%20assets/chessperiment/) — PNG pieces from [Chessperiment](https://chessperiment.app/), including all six black and white pieces.

See [`misc assets/README.md`](./misc%20assets/README.md) for each collection's source and licensing note.

### [chess-com-assets](./chess-com-assets/)

Chess.com-originated collections are outside `misc assets` because they have separate usage considerations:

- [`neo-main/`](./chess-com-assets/neo-main/) — the Neo main-piece set at 150 px.
- [`piece-themes/`](./chess-com-assets/piece-themes/) — all 38 standard Chess.com piece themes at 150 px. The catalog includes the canonical slugs and the `modern2` mapping for Modern.
