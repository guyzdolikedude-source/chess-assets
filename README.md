# chess-assets

A growing collection of chess-related visual assets from [Chess.com](https://www.chess.com/), Sashité, and other chess projects. The repository is a simple place to find piece sets and other resources for chess-related work.

## Assets

### [misc assets](./misc%20assets/)

The first collection is a public-domain western chess-piece set sourced from [Sashité's Chess Assets](https://sashite.dev/assets/chess/). It includes SVGs for every standard piece in both colors:

- [`white/`](./misc%20assets/white/) — king, queen, rook, bishop, knight, and pawn
- [`black/`](./misc%20assets/black/) — king, queen, rook, bishop, knight, and pawn

See [`misc assets/README.md`](./misc%20assets/README.md) for the source and licensing note for this set.
