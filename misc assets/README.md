# Misc assets

## [Sashité western chess pieces](./sashite/)

Public-domain western chess-piece SVGs sourced from [Sashité's Chess Assets](https://sashite.dev/assets/chess/).

| Folder | Contents |
| --- | --- |
| [`sashite/white/`](./sashite/white/) | First-player (white) king, queen, rook, bishop, knight, and pawn SVGs |
| [`sashite/black/`](./sashite/black/) | Second-player (black) king, queen, rook, bishop, knight, and pawn SVGs |

Sashité describes these SVGs as free, public-domain assets. Source: <https://sashite.dev/assets/chess/>.

## [Chessperiment chess pieces](./chessperiment/)

Standard black and white chess-piece PNGs from [Chessperiment](https://chessperiment.app/).

| Folder | Contents |
| --- | --- |
| [`chessperiment/`](./chessperiment/) | `black_*.png` and `white_*.png` files for the king, queen, rook, bishop, knight, and pawn |

Source: <https://chessperiment.app/>. Chessperiment is open source under the [MIT License](https://github.com/ItzMassel/Chessperiment/blob/main/LICENSE.md); see its [piece source directory](https://github.com/ItzMassel/Chessperiment/tree/main/client/public/pieces-v3) for the original assets.
