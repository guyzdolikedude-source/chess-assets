# Chess.com board themes

> These Chess.com-originated files may be subject to copyright, trademark, and Chess.com terms of use. This repository does not grant a license to copy, modify, distribute, or use them. Review the applicable Chess.com terms and obtain any required authorization before use.

This catalog contains the `150` variant of all 30 standard Chess.com board themes. Each board is stored as `<slug>/150.png`.

[`green/150.png`](./green/150.png) is the **main board**. A board endpoint's size identifies the square size; therefore every local `150.png` is a complete 8 × 8 board measuring **1200 × 1200 px**.

Canonical source URL pattern:

```text
https://images.chesscomfiles.com/chess-themes/boards/{slug}/150.png
```
