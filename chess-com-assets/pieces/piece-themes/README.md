# Chess.com piece themes

This catalog contains the **150 px** variant of all 38 standard Chess.com piece themes. Each theme is organized as `<slug>/150/` and has the same 12 files:

`wp.png`, `wn.png`, `wb.png`, `wr.png`, `wq.png`, `wk.png`, `bp.png`, `bn.png`, `bb.png`, `br.png`, `bq.png`, and `bk.png`.

Canonical source URL pattern:

```text
https://images.chesscomfiles.com/chess-themes/pieces/{slug}/150/{piece}.png
```
