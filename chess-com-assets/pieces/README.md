This directory groups the Chess.com piece collections:

- [`neo-main/`](./neo-main/) — the original Neo main-piece set at 150 px.
- [`piece-themes/`](./piece-themes/) — all 38 standard Chess.com piece themes at 150 px, organized by their canonical URL slugs.

For the full theme list, filenames, source URL pattern, and the `modern2` exception for Modern, see [`piece-themes/README.md`](./piece-themes/README.md).
